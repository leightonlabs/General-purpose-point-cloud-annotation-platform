# 文档索引

|---|---|
| 一期设计基线 | 已完成（本目录 01–07） |
| 一期代码首版 | 已提交至 annotation-platform 分支 `ccr-1e1b8e6c-6vsh3k`：立体框 + 逐点语义分割 + 提交校验 + 点云导出包 |
| 自动化测试 | 前端 21 项、后端 9 项通过；编辑器交互经浏览器冒烟验证 |
| 待办 | 协议评审、真实样本适配、联调与目标硬件性能测试、试标、验收（见 07 §5） |
