# 文档索引

三维点云作业平台的设计、规范与计划。点云作业台作为 [annotation-platform](https://github.com/leightonlabs/annotation-platform) 中的**独立模块**建设：只改点云自己的目录，调用（不修改）平台的任务、规范、权限、结算等中台能力；其它工作台与中台模块由伙伴开发者负责。
