## 原文：点云平台待确认问题



### 1.点云作业页面完全重构

 当前的点云作业页面只是一个占位，其按钮设计布局都是不合理的，现在给出你一个参考作业平台，在'**[General-purpose-point-cloud-annotation-platform](https://github.com/leightonlabs/General-purpose-point-cloud-annotation-platform)**根目录中，名称为'[4D点云分割作业平台结构.html](https://github.com/leightonlabs/General-purpose-point-cloud-annotation-platform/blob/main/4D点云分割作业平台结构.html)'。参考其结构和功能，最终的设计要按照实际功能来实现，比如现在的作业页面有个队列，实际工作中每个包都非常大，点云通常时一包多帧，在作业界面直接切换任务包可能会加载非常缓慢。页面的风格色彩保持和原来相似

### 2.规范库功能

项目绑定的是规范库，规范库功能要评估一下是否可用。他的设计可能不能适配每个作业平台，如果不可用，不使用也不更改此功能。仅使用它可用的功能，不足之处在作业平台页面使用完善相关功能即可。

### 3.任务派工时配置的作业台热键可用性

目前肯定是不可用的，默认配置0-9，且数量也有限。非必要可以不用，直接在作业平台页面设置好快捷键即可，附上快捷键列表窗口按钮，类似4D点云分割作业平台结构.html中的配置。



### 最新的要求要你首先实现点云作业

工作台，并形成可测试作业工作台的链路。

优先实现以下几个标注控件，之前的分阶段开发方案要根据此更改。

| 形态      | 控件                             | 控件用途解释                                                 |
| --------- | -------------------------------- | ------------------------------------------------------------ |
| 立体框    | 立方体                           | 在点云里画立方体，记录中心、长宽高和航向，单位是米。         |
| 逐点语义  | 刷点                             | 在点云上涂点，每个点一个类别。立体框不能代替逐点的类。       |
| 相机投影  | 3D 框投回图像                    | 用标定把点云里的框投回相机画面，核对是不是同一个目标。标定错了，投影全偏。这是计算，不是再画一个新框。 |
| 车道拓扑  | 中心线之间的连接；灯和车道的关系 | 除了车道中心线本身，还要标线与线怎么连，以及哪盏灯管哪条车道。 |
| 融合与 4D | 连续帧、鸟瞰、多传感器           | 把连续帧、鸟瞰图和多个传感器上的结果对到同一条轨迹，或同一片区域。 |
| 占用格子  | 空间格子                         | 把空间划成格子。每一格标空着、被占或未知，以及静止、运动和类别。不是立体框，也不是逐点涂类。 |
