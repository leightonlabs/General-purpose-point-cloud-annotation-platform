## 1. 界面布局

从“待办任务 / 质检 / 审核 / 任务详情”打开点云明细后，点云作业台全屏显示：

```text
┌ 顶栏：← 返回 · 点云作业台 · 任务名 · 样本编码 · [标注|质检|审核|只读] · 返工原因 ……  保存状态 · ↶ ↷ · 上一条 3/120 下一条 · 项目工具 · 保存 / 提交（质检：驳回原因 · 驳回说明 · 驳回 · 通过） ┐
├──────────────┬──────────────────────────────────────────────────────────┬───────────────┬──────────────────┤
│ 左栏          │ 编辑器工具栏：[目标|分割] 工具 · 着色 · 点大小 · 显示 z · 地面 · 视角 │ 编辑器侧栏      │ 右栏               │
│ 立体框类别 /  │                                                          │ 目标模式：       │ [对象 n] [问题 a/b] │
│ 分割类别      │                三维视口（three.js）                        │  三视图          │ 对象：框列表、       │
│ 色块 · 名称 · │                                                          │  中心/长宽高/航向 │   选中框类别与属性、 │
│ 数字键        │                                                          │  跟踪 ID         │   删除              │
│              │ 状态行：格式 · 有效/总点数 · 框数或未标注数 · 提示            │ 分割模式：       │ 问题：提问题、       │
│              │                                                          │  类别点数、隐藏   │   待改 / 已解决      │
└──────────────┴──────────────────────────────────────────────────────────┴───────────────┴──────────────────┘
```

| 区域 | 内容 |
|---|---|
| 顶栏 | 阶段标签（标注 / 质检 / 审核 / 只读）；返工时显示驳回原因；保存状态（未保存 / 保存中… / 已保存 时间 / 保存失败，已暂存本机）；撤销、重做；队列内上一条、下一条与序号；“项目工具”（有项目编辑或数据集导出权限时显示） |
| 左栏 | 当前模式可用的类别（来自类别作业方式，[04 §2](./04-项目规范配置.md#2-类别作业方式)），前 10 个依次对应数字键 1–9、0；点击切换当前类，目标模式下选中框时同时改该框类别 |
| 编辑器 | 点云加载与显示、两种模式的工具（§2）；侧栏为三视图与数值面板（目标模式）或分割类别统计（分割模式） |
| 右栏 · 对象 | 全部立体框（序号、类别、跟踪 ID，必填属性未填时显示红色“!”）；选中框的类别与属性表单；删除 |
| 右栏 · 问题 | 质检员提问题；全部问题按“待改 / 已解决”显示，点击挂在框上的问题定位到该框 |

提示条：红色 = 不能继续（规范中没有可用类别、逐点标签编码不支持 / 损坏 / 与点云文件不一致）；黄色 = 需要注意（点数多于 200 万、点云文件与上次保存时不同）。

## 2. 模式与工具

| 模式 | 工具 | 操作 |
|---|---|---|
| 目标 | 选择（V） | 单击框选中，单击空白取消；在空白处拖动旋转视角 |
| 目标 | 新建框（C） | 在地面上按住拖出底面矩形；松手生成框：高度按底面内高于地面的最高点估计（无点时 1.6 m，最低 0.3 m），朝向沿长边 |
| 目标 | 平移（T）/ 旋转（R）手柄 | 选中框后在视口中拖手柄；旋转只绕竖直轴 |
| 目标 | 贴合（A） | 保持朝向，按框外扩 0.3 m 范围内、地面以上的点收紧框；底面落到地面高度 |
| 目标 | 掉头（U） | 航向 +180° |
| 目标 | 三视图 | 俯视（上 = 车头）、侧视（右 = 车头）、后视（从车尾看）；拖框内平移、拖边改尺寸（对边不动）、俯视图拖橙色圆点旋转、滚轮缩放 |
| 目标 | 数值面板 | 直接输入中心、长宽高、航向；填写跟踪 ID；“自动编号跟踪 ID”给尚无 ID 的框按现有最大数字 + 1 依次编号 |
| 分割 | 套索（L） | 按住画任意形状，松手对形状内的点赋当前类 |
| 分割 | 矩形（R） | 拖出矩形赋类 |
| 分割 | 笔刷（B） | 按住涂抹；`[` `]` 调半径 |
| 分割 | 涂抹 / 擦除（X） | 擦除把点恢复为未标注 |
| 分割 | 覆盖已标注（W） | 默认关闭：只改未标注点；打开后可改已标注点 |
| 分割 | 框内点赋类（I） | 把当前选中框内的点赋给当前类（受“覆盖已标注”限制） |
| 分割 | 类别统计 | 各类点数与未标注数；眼睛图标隐藏该类的点（隐藏的点不会被选中）；已不在规范中的类别标红 |

**选区穿透说明**：套索、矩形、笔刷作用于视口中所有**显示中的点**，包括被前景遮挡的点。限定范围的手段：调“显示 z”裁剪高度、隐藏已完成的类别、保持“仅改未标注”、切到俯视或侧视角度再选。

## 3. 快捷键

点云作业台在页面级统一处理按键，**作业台壳原有的快捷键（Q/E 最近类别、/ 类别面板、Tab、Enter 提交、方向键或 `[` `]` 切换上下条等）在点云作业台不生效**。输入框、下拉框获得焦点或弹窗打开时，快捷键不生效。

**作业台级（两种模式通用）**

| 键 | 作用 |
|---|---|
| Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z） | 撤销 / 重做（框、分割、属性、问题统一一条历史，最多 50 步；切换样本后清空） |
| Ctrl+S | 立即保存 |
| Ctrl+Enter | 标注：提交；质检 / 审核：通过 |
| 1–9、0 | 选当前模式下第 1–10 个类别；目标模式下选中框时同时改该框类别 |
| Delete / Backspace | 目标模式下删除选中框 |
| Esc | 取消正在进行的拖拽或选区；否则取消选中 |

**编辑器级**

| 键 | 目标模式 | 分割模式 |
|---|---|---|
| M | 切换到分割模式 | 切换到目标模式 |
| F | 选中框时聚焦该框，否则适应视图 | 适应视图 |
| G | 俯视 / 透视切换 | 同左 |
| V / C | 选择 / 新建框 | — |
| T / R | 平移 / 旋转手柄 | R：矩形选区 |
| A / U | 贴合 / 掉头 | — |
| ↑ ↓ ← → | 沿框朝向前后、左右移 0.05 m（Shift ×5） | — |
| PgUp / PgDn | 上下移 0.05 m（Shift ×5） | — |
| Z / X | 航向 +1° / −1°（Shift ×5） | X：涂抹 / 擦除切换 |
| L / B | — | 套索 / 笔刷 |
| W / I | — | 覆盖已标注开关 / 框内点赋类 |
| [ / ] | — | 笔刷半径 −4 / +4 像素 |
| Alt + 左键拖动 | 新建框工具下旋转视角 | 任意工具下旋转视角 |

## 5. 显示控制

| 控件 | 说明 |
|---|---|
| 着色 | 按高度（默认）、按强度（有强度字段时）、RGB（有颜色时默认）、按类别 |
| 点 | 点大小（像素） |
| 显示 z | 只显示该高度范围内的点；**选区也只作用于显示中的点**，是分割时排除地面 / 天花板的主要手段 |
| 地面 | 新建框落地高度；初值为自动估计值 |
| 选中框高亮 | 目标模式下选中框内的点显示为黄色，状态栏显示框内点数，用于检查贴合 |

## 6. 保存、恢复与离开

| 场景 | 行为 |
|---|---|
| 自动保存 | 最后一次修改后 3 秒自动保存到服务器（标注阶段存草稿，质检 / 审核阶段存质检改动与问题单） |
| 手动保存 | 顶栏“保存”或 Ctrl+S |
| 保存失败 | 顶栏显示“保存失败，已暂存本机”，结果写入浏览器本机（按明细区分）；下次打开该明细时提示“恢复 / 丢弃” |
| 切换上一条 / 下一条、返回 | 先保存再跳转 |
| 关闭或刷新页面 | 有未保存改动时浏览器弹出离开确认 |
| 提交 / 通过 / 驳回成功 | 自动进入队列下一条；没有下一条时回到对应列表 |

## 7. 立体框作业标准

以下为一期默认标准，项目可在说明中按甲方规范收紧或放宽，但必须写明。

### 7.1 标什么

1. 作业范围内（默认整帧，或项目说明中的半径 / 区域）属于规范类别的目标都要标注。
2. 目标点数下限默认 **5 个点**：少于 5 个点且无法判断类别的目标不标；项目可另行规定。
3. 被遮挡、截断的目标照常标注，并填写遮挡 / 截断属性。

### 7.2 框怎么拉

| 要求 | 默认标准 |
|---|---|
| 贴合 | 框的每个面贴住目标最外侧的点，偏差 ≤ 0.1 m（或该边尺寸的 5%，取大者）；不得把地面点、相邻目标的点包进框 |
| 完整外形 | 只看到局部的目标（如只扫到车尾），按甲方规范选择：**A. 按可见点贴合**，或 **B. 按同类目标典型尺寸补全外形**；项目必须二选一写入说明 |
| 底面 | 底面落在地面上（贴合后自动处理）；悬空目标（如被举起的物体）按实际 |
| 朝向 | 车辆朝车头方向；行人朝面部 / 行进方向；无法判断时按运动方向或道路方向；误差 ≤ 5°（车辆）/ ≤ 15°（行人） |
| 跟踪 ID | 需要时填写；同一目标在序列内一致（[04 §5](./04-项目规范配置.md#5-跟踪-id-规范)） |

### 7.3 推荐操作顺序

```text
G 俯视找目标 → 数字键选类别 → C 拖底面 → V 选中 → A 贴合
  → 三视图检查：俯视看朝向与长宽，侧视 / 后视看高度与地面
  → 必要时拖边或方向键微调 → U 修正朝向
  → 右栏“对象”填属性，编辑器侧栏填跟踪 ID → 下一个目标
```

## 8. 逐点分割作业标准

### 8.1 推荐顺序

1. 混合项目先在目标模式把需要实例边界的目标拉框，再按 M 进入分割模式；纯分割项目直接进入分割模式。
2. **先大后小**：用“显示 z”只显示地面附近高度，俯视矩形 / 套索赋“路面”“人行道”等地面类。
3. 调回全高度，隐藏已完成的地面类，再处理建筑、植被等大面积类别。
4. 最后处理车辆、行人等前景：可用框内点赋类（I），再用笔刷修边界。
5. 打开“覆盖已标注（W）”只用于纠错，纠错完关闭。

### 8.2 质量要求

| 要求 | 默认标准 |
|---|---|
| 完整性 | 作业范围内未标注点为 0（无法判断的点标“其他 / 忽略”） |
| 正确性 | 每个目标内错标点 ≤ 2%；目标之间、目标与地面交界处按项目边界规则 |
| 一致性 | 同一类物体在同一序列内标法一致 |

## 9. 提交前自检

| # | 检查 | 方法 |
|---|---|---|
| S1 | 无漏标目标 | 俯视全局扫一遍；按高度着色看突起物 |
| S2 | 框贴合与朝向 | 逐个选中看三视图与框内高亮点 |
| S3 | 必填属性已填 | 右栏对象列表无红色“!”；提交时校验会列出缺失项 |
| S4 | 跟踪 ID 无重复 | 提交时校验 |
| S5 | 未标注点 | 分割统计“未标注”计数；提交时提醒数量与占比 |
| S6 | 已处理质检问题（返工时） | 右栏“问题”中待改项逐条修改并“标记已解决” |

提交校验分两级：**硬错误**必须修改；**提醒**可确认“仍要继续”（规则见 [03 §7](./03-标注结果协议.md#7-校验规则)）。前端通过后，后端还会做一次严格校验，失败时提示具体原因。

## 10. 质检员操作

| 操作 | 方法 |
|---|---|
| 直接修改 | 质检 / 审核打开同一作业台，可改框、改分割、改属性；改动自动保存，不改变明细状态 |
| 提问题 | 右栏“问题”：选问题类型（驳回原因模板），写“对象 + 现象 + 期望”；目标模式选中框后点“对选中框提问题”（问题挂到该框），否则点“整帧问题” |
| 通过 | 顶栏“通过”或 Ctrl+Enter；先做与提交相同的校验，带上质检改动一并通过 |
| 驳回 | 顶栏选“驳回原因”、填“驳回说明”后点“驳回”。驳回原因、说明、待改问题三者至少有一项；驳回理由自动拼接为“说明（或原因名）；问题类型（第 n 个框 / 整帧）：问题正文；…”，返工时显示在作业台顶栏，问题本身保留在右栏“问题”中 |
| 删除问题 | 质检 / 审核可删除问题；标注员只能标记已解决或重新打开 |

问题写法见 [06 §5.4](./06-作业流程与质量规范.md#54-问题单写法)。

## 11. 使用建议

- 浏览器：Chrome / Edge 最新稳定版，开启硬件加速（WebGL 2）；内存 ≥ 16 GB 处理百万级点云。
- 点数较多时：先裁剪高度、隐藏类别再做选区；笔刷半径不要过大。
- 网络中断时继续作业即可：保存失败的结果暂存本机，恢复网络后按 Ctrl+S 或继续修改会重新保存；换电脑前务必确认顶栏显示“已保存”。
