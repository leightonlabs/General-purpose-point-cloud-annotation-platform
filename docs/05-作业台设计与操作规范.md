## 1. 界面布局

│                                       │                                              │ 目标模式：     │              │
│                                       │            三维视口（three.js）               │  三视图        │              │
│                                       │                                              │  框数值/跟踪ID │              │
│                                       │                                              │ 分割模式：     │              │

- 壳负责：领取后的草稿自动保存（停手 5 秒写云端，并落本地）、撤销/重做、提交前校验、质检批注、上下条导航。
- 点云编辑器负责：点云加载与显示、两种模式的工具、结果写回壳。
- 顶部提示条：红色 = 不能继续（规范没有可用类别、点云与已存标签不一致）；黄色 = 需要注意（点数多、文件与上次保存不同）。

## 2. 模式与工具

| 模式 | 工具 | 操作 |
|---|---|---|
| 目标 | 选择（V） | 单击框选中，单击空白取消；在空白处拖动旋转视角 |
| 目标 | 新建框（C） | 在地面上按住拖出底面矩形；松手生成框：高度按底面内高于地面 0.1 m 的最高点估计（无点时 1.6 m），朝向沿长边（默认指向屏幕上方，横向更长时指向屏幕右方） |
| 目标 | 平移（T）/ 旋转（R）手柄 | 选中框后在视口中拖手柄；旋转只绕竖直轴 |
| 目标 | 贴合（A） | 保持朝向，按框外扩 0.3 m 范围内、地面以上的点收紧框；底面落到地面高度 |
| 目标 | 掉头（U） | 航向 +180° |
| 目标 | 三视图 | 俯视（上 = 车头）、侧视（右 = 车头）、后视（从车尾看）；拖框内平移、拖边改尺寸（对边不动）、俯视图拖橙色圆点旋转、滚轮缩放 |
| 目标 | 数值面板 | 直接输入中心、长宽高、航向；填写跟踪 ID；“自动编号跟踪 ID” |
| 分割 | 套索（L） | 按住画任意形状，松手对形状内的点赋当前类 |
| 分割 | 矩形（R） | 拖出矩形赋类 |
| 分割 | 笔刷（B） | 按住涂抹；`[` `]` 调半径 |
| 分割 | 涂抹 / 擦除（X） | 擦除把点恢复为未标注 |
| 分割 | 覆盖已标注（W） | 默认关闭：只改未标注点；打开后可改已标注点 |
| 分割 | 框内点赋类（I） | 把当前选中框内的点赋给当前类（受“覆盖已标注”限制） |
| 分割 | 类别列表 | 点击切换当前类；眼睛图标隐藏该类的点（隐藏的点不会被选中） |

**选区穿透说明**：套索、矩形、笔刷作用于视口中所有**显示中的点**，包括被前景遮挡的点。限定范围的手段：调“显示 z”裁剪高度、隐藏已完成的类别、保持“仅改未标注”、切到俯视或侧视角度再选。

## 3. 快捷键

作业台壳原有快捷键继续有效：数字 1–9/0 选类别、Q/E 切最近类别、/ 打开类别面板、Ctrl+Z / Ctrl+Y 撤销重做、Delete 删除选中框、Esc 取消选中、Enter 提交（质检模式为通过）、Tab 下一个图形。点云编辑器新增：

| 键 | 目标模式 | 分割模式 |
|---|---|---|
| M | 切换到分割模式 | 切换到目标模式 |
| F | 选中框时聚焦该框，否则适应视图 | 适应视图 |
| G | 俯视 / 透视切换 | 同左 |
| V / C | 选择 / 新建框 | — |
| T / R | 平移 / 旋转手柄 | R：矩形选区 |
| A / U | 贴合 / 掉头 | — |
| ↑ ↓ ← → | 沿框朝向前后、左右移 0.05 m（Shift ×5） | — |
| PgUp / PgDn | 上下移 0.05 m（Shift ×5） | — |
| Z / X | 航向 +1° / −1°（Shift ×5） | X：涂抹 / 擦除切换 |
| L / B | — | 套索 / 笔刷 |
| W / I | — | 覆盖已标注开关 / 框内点赋类 |
| [ / ] | — | 笔刷半径 −4 / +4 像素 |
| Alt + 左键拖动 | 新建框工具下旋转视角 | 任意工具下旋转视角 |

编辑器消费的按键不再传给壳（例如方向键、`[` `]` 在点云作业台不会跳到上下条）；输入框获得焦点时快捷键不生效。

## 5. 显示控制

| 控件 | 说明 |
|---|---|
| 着色 | 按高度（默认）、按强度（有强度字段时）、RGB（有颜色时默认）、按类别 |
| 点 | 点大小（像素） |
| 显示 z | 只显示该高度范围内的点；**选区也只作用于显示中的点**，是分割时排除地面/天花板的主要手段 |
| 地面 | 新建框落地高度；初值为自动估计值 |
| 选中框高亮 | 目标模式下选中框内的点显示为黄色，用于检查贴合 |

## 6. 立体框作业标准

以下为一期默认标准，项目可在说明中按甲方规范收紧或放宽，但必须写明。

### 6.1 标什么

1. 作业范围内（默认整帧，或项目说明中的半径/区域）属于规范类别的目标都要标注。
2. 目标点数下限默认 **5 个点**：少于 5 个点且无法判断类别的目标不标；项目可另行规定。
3. 被遮挡、截断的目标照常标注，并填写遮挡/截断属性。

### 6.2 框怎么拉

| 要求 | 默认标准 |
|---|---|
| 贴合 | 框的每个面贴住目标最外侧的点，偏差 ≤ 0.1 m（或该边尺寸的 5%，取大者）；不得把地面点、相邻目标的点包进框 |
| 完整外形 | 只看到局部的目标（如只扫到车尾），按甲方规范选择：**A. 按可见点贴合**，或 **B. 按同类目标典型尺寸补全外形**；项目必须二选一写入说明 |
| 底面 | 底面落在地面上（贴合后自动处理）；悬空目标（如被举起的物体）按实际 |
| 朝向 | 车辆朝车头方向；行人朝面部/行进方向；无法判断时按运动方向或道路方向；误差 ≤ 5°（车辆）/ ≤ 15°（行人） |
| 跟踪 ID | 需要时填写；同一目标在序列内一致（[04 §5](./04-项目规范配置.md#5-跟踪-id-规范)） |

### 6.3 推荐操作顺序

```text
G 俯视找目标 → C 拖底面 → V 选中 → A 贴合
  → 三视图检查：俯视看朝向与长宽，侧视/后视看高度与地面
  → 必要时拖边或方向键微调 → U 修正朝向
  → 填类别属性与跟踪 ID → 下一个目标
```

## 7. 逐点分割作业标准

### 7.1 推荐顺序

1. 先在目标模式把需要实例边界的目标拉框（混合项目），或直接进入分割模式。
2. **先大后小**：用“显示 z”只显示地面附近高度，俯视矩形/套索赋“路面”“人行道”等地面类。
3. 调回全高度，隐藏已完成的地面类，再处理建筑、植被等大面积类别。
4. 最后处理车辆、行人等前景：可用框内点赋类（I），再用笔刷修边界。
5. 打开“覆盖已标注（W）”只用于纠错，纠错完关闭。

### 7.2 质量要求

| 要求 | 默认标准 |
|---|---|
| 完整性 | 作业范围内未标注点为 0（无法判断的点标“其他/忽略”） |
| 正确性 | 每个目标内错标点 ≤ 2%；目标之间、目标与地面交界处按项目边界规则 |
| 一致性 | 同一类物体在同一序列内标法一致 |

## 8. 提交前自检

| # | 检查 | 方法 |
|---|---|---|
| S1 | 无漏标目标 | 俯视全局扫一遍；按高度着色看突起物 |
| S2 | 框贴合与朝向 | 逐个选中看三视图 |
| S3 | 必填属性已填 | 提交时校验会列出缺失项 |
| S4 | 跟踪 ID 无重复 | 提交时校验 |
| S5 | 未标注点 | 分割面板“未标注”计数；提交时提醒数量与占比 |
| S6 | 已解决质检问题（返工时） | 右栏问题列表全部处理 |

提交校验分两级：**硬错误**必须修改；**提醒**可确认后继续（规则见 [03 §7](./03-标注结果协议.md#7-校验规则)）。

## 9. 质检员操作

- 质检/审核打开同一作业台；可直接改框、改分割后“改完并通过”（与原平台一致），改动保留三维字段和分割层。
- 提问题：目标模式选中框后点“对此框提问题”，或点“整帧问题”；问题类型选驳回原因模板，正文写清对象和现象（见 [06 §5.4](./06-作业流程与质量规范.md#54-问题单写法)）。
- 驳回后标注员在右栏“待改问题”逐条处理并标记已解决。

## 10. 使用建议

- 浏览器：Chrome / Edge 最新稳定版，开启硬件加速（WebGL 2）；内存 ≥ 16 GB 处理百万级点云。
- 点数较多时：先裁剪高度、隐藏类别再做选区；笔刷半径不要过大。
- 网络中断时草稿仍落本地，恢复后重新打开任务会提示恢复本地草稿。
