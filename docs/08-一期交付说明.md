## 3. 实现要点

### 3.1 与平台的衔接方式

```mermaid
sequenceDiagram
    participant U as 作业员
    participant S as 作业台壳（未改动）
    participant L as LidarEditor（入口）
    participant W as PointCloudWorkbench
    participant P as /api/labeling/pointcloud
    participant T as 中台 TaskService（未改动）
    U->>S: 打开明细 /workbench/:itemId
    S->>L: mediaType = lidar，按原约定挂载
    L->>W: 全屏挂载（Teleport），document 级按键截断
    W->>T: GET task/items/:id/workbench（只读）
    W->>P: GET projects/:projectId/config
    U->>W: 标注（自动保存 3 秒）
    W->>P: POST items/:id/draft
    P->>P: 宽松规范化，写 annotations_json
    P->>T: saveDraftItem（不带整包）
    U->>W: 提交
    W->>P: POST items/:id/submit
    P->>P: 严格校验，写 annotations_json
    P->>T: submitItem（不带整包，按当前整包计量结算）
```

- **按键隔离**：作业台在 `document` 上监听按键并始终 `stopPropagation()`，壳挂在 `window` 上的快捷键收不到点云页面的按键。
- **结果隔离**：入口组件从不向壳发出 `update:snapshot` / `dirty`，壳没有可保存的内容，不会调用通用保存 / 提交接口（浏览器冒烟中计数为 0）。
- **事务**：点云服务方法 `@Transactional`，写整包与中台流转同成同败；中台校验失败（如非执行人、状态不对）时整包写入一并回滚。

### 3.2 关键约定

- 逐点标签下标 = 文件原始点序；`pointSeg.pointCount` / `digest` 必须与 `pointCloud` 一致，否则作业台禁止分割编辑与提交、后端拒绝提交。
- `rle-varint-v1`：按 (值, 游程) 写 LEB128 变长整数后 base64；前后端用同一组测试向量校验。
- 立体框 `center` 为几何中心、原始坐标；航向角落库为度（[0, 360)，绕 +Z 逆时针，0 指向 +X）；OpenPCDet 导出换算为弧度 [-π, π)。
- 类别作业方式存 `lbl_pc_project_config.config_json`：`{"classModes":{"<classId>":["cuboid","point_seg"]}}`；未配置的类别默认只拉立体框。
